# Persistent implementation roadmap

Updated 2026-09-23. Status vocabulary: **done** = implemented and verified acceptance below; **todo** = unavailable; **partial** = explicit subset only; **deferred** = outside first release; **tracked** = alias to named tasks, not completed functionality. IDs are stable; append tasks rather than renumbering them. “Done” applies to a task, never automatically to its whole milestone. The task tables use short references `01`–`09` for the corresponding specs listed in the [wiki index](index.md); P/A/B/E/G case IDs are defined in [conformance](conformance.md). Bootstrap-only checks are named by executable test target when the specification has no exact case.

Requirements C01–C19 and defaults D01–D23 in the decision register define the current plan. Retain G-AUTH/G-SSH/G-PROVIDER/G-DURABILITY/G-LIMITS and added object/function gates until evidence is recorded. No public data release may bypass them. Bootstrap completed only a subset of M0/M1, not the first usable release.
